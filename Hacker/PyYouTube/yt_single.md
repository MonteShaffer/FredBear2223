# Windows 11 Setup
* Install Python
* Install `pytubefix`
```
pip install pytubefix
```
* Run script yt_single.py from CMD line 
Browse to yt_single.py folder and right click, Open in Terminal

```
python ./yt_single.py 
```

```
python ./yt_single.py -k 9bZkp7q19f0
```

```
python ./yt_single.py -k _d2BCEI9DxA 
```


* More information
https://github.com/JuanBindez/pytubefix

* setup ffmpeg for .cli.py to also work on larger/newer videos

Audio and Video are separately streamed and then ffmpeg merges them into mp4
